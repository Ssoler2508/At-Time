# Addy: rendimiento y Web Vitals

- HTML5 semántico estricto (`header`, `main`, `section`, `footer`, `nav`).
- Enfoque 100% mobile-first con CSS nativo usando variables de `src/styles/tokens.css`.
- Cero JavaScript innecesario en el cliente; aprovechar islas de Astro solo cuando haya interactividad real.
- Imágenes y SVGs optimizados con dimensiones explícitas para evitar saltos visuales (CLS).
